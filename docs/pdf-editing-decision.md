# PDF編集機能に関する決定記録

## 状態

- 決定日: 2026-09-06
- 結論: PDRへのPDF編集機能の追加は中止

## 決定内容

PDFのページ入れ替え、挿入、削除、回転、自動傾き補正、上書き保存、
名前を付けて保存は、別のアプリケーションで行う。

PDRではこれらの新機能を実装せず、既存のPDF閲覧機能に集中する。

## 維持する変更

実装準備として行ったフェーズ0のコード整理は、既存機能にも有効なため維持する。

- PDFiumの初期化、描画ワーカー、目次抽出を `src/pdf_worker.rs` に分離
- ページ表示と移動に関する計算を `src/navigation.rs` に分離
- ページ移動計算の単体テストを追加
- プロジェクトのバージョンを `0.2.0` に更新

フェーズ0では、PDF編集機能そのものは追加していない。

## 調査結果の要約

フェーズ1では `pdfium-render 0.9.2` の公開APIを確認し、削除、ページのコピー、
回転、保存に利用できるAPIがあることを確認した。一方、ページ移動を直接行う
高水準APIは確認できず、コピーと削除で代替する場合は、しおり、フォーム、署名などを
含むPDFへの影響を追加検証する必要があった。

方針変更により、編集バックエンドの選定と製品コードへの実装は行っていない。
調査用の一時コードも製品コードには残していない。

## 実施しない項目

- 編集バックエンドと編集セッションの実装
- ページの入れ替え、挿入、削除、回転
- 自動傾き補正
- 編集結果の即時プレビュー
- 上書き保存、名前を付けて保存
- 編集UI、統合テスト、編集機能のリリース作業
